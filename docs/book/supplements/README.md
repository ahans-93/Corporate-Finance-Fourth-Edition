# Lampiran asli kompilasi rumus

Tiga berkas ini merupakan bahan yang diberikan untuk melengkapi repository:

| Format | Berkas |
| --- | --- |
| Markdown | [kompilasi_rumus_corporate_finance.md](kompilasi_rumus_corporate_finance.md) |
| LaTeX | [kompilasi_rumus_corporate_finance.tex](kompilasi_rumus_corporate_finance.tex) |
| PDF, 11 halaman | [kompilasi_rumus_corporate_finance.pdf](kompilasi_rumus_corporate_finance.pdf) |

PDF semula bernama download.pdf; nama berkas dibuat lebih jelas tanpa mengubah isinya. Ukuran dan SHA-256 dicatat dalam [manifest lampiran](../../../data/formula-supplement-manifest.json).

Berkas asli tetap versi awal dan dapat mengandung penyederhanaan atau klaim cakupan yang belum dibuktikan. Gunakan [versi telaah](../53-kompilasi-rumus.md) dan [catatan koreksi](../54-catatan-koreksi-rumus.md) untuk asumsi serta perbaikan. Koreksi pada versi telaah belum diterapkan ke PDF dan LaTeX asli.
