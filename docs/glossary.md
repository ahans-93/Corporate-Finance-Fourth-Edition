# Glosarium keuangan perusahaan

| Istilah | Makna praktis |
| --- | --- |
| Accrual | Pengakuan transaksi ketika hak atau kewajiban timbul sesuai basis akrual, bukan hanya ketika kas berpindah |
| Agency cost | Kerugian dan biaya pengendalian akibat perbedaan kepentingan antar-pihak |
| APV | Nilai operasi tanpa leverage ditambah dampak pendanaan yang dinilai terpisah |
| Arbitrage | Strategi memanfaatkan perbedaan harga dengan karakter risiko dan arus kas yang setara dalam kerangka model |
| Asset turnover | Penjualan dibagi modal/aset yang didefinisikan konsisten |
| Beta | Sensitivitas return aset terhadap return pasar |
| Book value | Nilai yang tercatat menurut kebijakan akuntansi |
| Bought deal | Penempatan ketika penjamin membeli sekuritas lebih awal dan menanggung risiko distribusi |
| Book-building | Pengumpulan minat investor untuk membantu menetapkan harga dan alokasi penerbitan |
| Call option | Hak membeli underlying pada ketentuan tertentu |
| Capital employed | Modal yang digunakan pada aset operasi dan modal kerja dalam definisi analitis |
| Capital structure | Komposisi klaim pendanaan, terutama utang dan ekuitas |
| Capex | Pengeluaran investasi aset jangka panjang |
| CAPM | Model required return berbasis risiko pasar melalui beta |
| Cash conversion cycle | DSO ditambah DIO dikurangi DPO |
| CFADS | Arus kas tersedia untuk layanan utang menurut definisi kontrak |
| CFO | Dapat berarti chief financial officer atau cash flow from operations; baca konteks |
| Collateral | Aset atau hak yang dijadikan jaminan |
| Consolidation | Penyajian kelompok usaha sebagai satu entitas ekonomi |
| Control | Kemampuan mengarahkan aktivitas relevan; tidak selalu sama dengan persentase saham ekonomis |
| Convertible bond | Obligasi dengan hak atau ketentuan konversi menjadi saham |
| Convexity | Ukuran kelengkungan hubungan harga obligasi dengan yield |
| Covenant | Pembatasan atau kewajiban kontraktual dalam pembiayaan |
| Credit spread | Selisih yield terhadap acuan, yang dapat memuat risiko kredit dan komponen lain |
| DCF | Valuasi dengan mendiskonto arus kas masa depan |
| Dilution | Penurunan proporsi atau metrik per saham; tidak otomatis sama dengan kehilangan nilai ekonomi |
| DIO | Hari persediaan berdasarkan denominator yang dinyatakan |
| DPO | Hari pembayaran utang usaha berdasarkan pembelian yang konsisten |
| DSO | Hari penagihan piutang berdasarkan penjualan kredit yang konsisten |
| DSCR | CFADS dibagi pembayaran bunga dan pokok yang jatuh tempo |
| Duration | Waktu tertimbang arus kas obligasi dan dasar ukuran sensitivitas bunga |
| EBIT | Laba sebelum bunga dan pajak |
| EBITDA | Laba sebelum bunga, pajak, depresiasi, dan amortisasi; bukan saldo kas |
| Economic profit | NOPAT dikurangi beban modal |
| Enterprise value | Nilai operasi untuk seluruh klaim yang dicakup dalam arus kas valuasi |
| Equity value | Nilai yang menjadi hak pemegang ekuitas setelah adjustment klaim lain |
| EVA | Istilah economic value added untuk bentuk laba ekonomi, dengan penyesuaian yang dapat berbeda |
| FCFE | Arus kas bebas untuk pemegang saham setelah pendanaan utang |
| FCFF | Arus kas bebas bagi seluruh penyandang modal sebelum pembagian pendanaan |
| Forward | Kontrak harga atau rate untuk transaksi masa depan |
| Free float | Saham yang tersedia untuk perdagangan publik sesuai definisi pasar yang dipakai |
| Goodwill | Selisih dalam pengukuran kombinasi bisnis yang perlu dibaca bersama dasar akuntansinya |
| Hedging | Mengurangi exposure risiko tertentu melalui pengaturan ekonomi atau instrumen |
| IRR | Tingkat diskonto yang menghasilkan NPV nol |
| Liquidity | Kemampuan memperoleh dana dan memenuhi pembayaran tepat waktu |
| LBO | Akuisisi dengan porsi pembiayaan utang yang besar |
| Maturity | Tanggal jatuh tempo |
| MVA | Selisih nilai pasar yang didefinisikan dengan modal buku pembanding |
| NCI | Kepentingan nonpengendali pada entitas konsolidasian |
| Net debt | Utang keuangan dikurangi kas/aset kas yang memenuhi definisi analitis |
| NOPAT | Laba operasi setelah pajak operasi normal |
| NPV | Nilai kini seluruh cash flow tambahan termasuk investasi awal |
| Opportunity cost | Manfaat alternatif terbaik yang dilepas |
| Payback | Waktu pengembalian investasi menurut ukuran kas yang dipilih |
| Pecking order | Kerangka preferensi pendanaan internal, utang, lalu ekuitas saat terdapat friksi informasi |
| Perpetuity | Rangkaian arus kas tanpa batas periode |
| Put option | Hak menjual underlying pada ketentuan tertentu |
| Recourse | Hak menagih kembali kepada pihak pengalih risiko atau penjual aset sesuai kontrak |
| Reinvestment | Dana yang ditanam kembali untuk mempertahankan atau menumbuhkan operasi |
| Rights issue | Penerbitan saham dengan hak subscription bagi pemegang yang memenuhi syarat |
| ROCE | Hasil operasi setelah pajak terhadap capital employed |
| ROE | Laba pemegang saham dibanding ekuitas buku yang sesuai |
| Runway | Perkiraan waktu sampai kas tersedia habis berdasarkan burn dan skenario |
| Scissors effect | Margin berubah karena pendapatan dan biaya bergerak pada laju berbeda |
| Seniority | Urutan prioritas pembayaran klaim |
| Solvency | Kecukupan kemampuan/nilai aset untuk memenuhi kewajiban pada konteks penilaian |
| Spot rate | Tingkat diskonto tanpa kupon untuk tenor tertentu |
| Subordinated debt | Utang dengan prioritas di bawah klaim tertentu |
| Synergy | Manfaat tambahan kombinasi dibanding usaha berdiri sendiri setelah biaya |
| Tax shield | Penghematan pajak yang dapat dimanfaatkan akibat pengurang pajak tertentu |
| TERP | Harga teoritis saham setelah rights issue |
| Terminal value | Nilai pada akhir periode proyeksi eksplisit atas arus kas setelahnya |
| TSR | Return investor dari perubahan harga dan distribusi dalam horizon tertentu |
| Underwriting | Penjaminan penerbitan sesuai komitmen dan risiko kontrak |
| VaR | Kuantil kerugian pada horizon dan confidence tertentu; bukan kerugian maksimum |
| WACC | Rata-rata tertimbang required return utang dan ekuitas dengan perlakuan pajak konsisten |
| Working capital | Modal yang terikat dalam siklus operasi sesuai definisi model |
| Yield to maturity | IRR obligasi pada harga dan jadwal pembayaran yang diasumsikan |

Untuk penggunaan istilah dalam konteks, lihat [daftar isi](../SUMMARY.md) dan [rumus lanjutan](advanced-formulas.md).
